## Descrição do projeto 

<p align="justify">
    Este projeto faz parte da <b>Trilha de CSS da DIO (Digital Innovation One)</b> e tem como objetivo aplicar na prática os fundamentos do CSS, construindo uma <b>Landing Page responsiva</b> e visualmente agradável utilizando <b>HTML e CSS puros</b>.

Durante o desafio, foram exploradas as <b>propriedades básicas de estilização</b>, o uso de <b>unidades de medida relativas e absolutas</b>, e boas práticas de <b>organização de código e estrutura de layout</b>.
</p>


## Funcionalidades

:heavy_check_mark: Estilização completa com **CSS3**;

:heavy_check_mark: Navegação simples e intuitiva;

:heavy_check_mark: Tipografia e cores personalizadas;

:heavy_check_mark: Imagens otimizadas para melhor desempenho e estética;

:heavy_check_mark: Inclusão de links e botões estilizados;

:heavy_check_mark: Design moderno e minimalista, inspirado em boas práticas de UI.

## Acesso ao projeto

No terminal, clone o projeto: 

```
git clone git@github.com:francinevsouza/trilha-css-desafio-dio.git
```


## Abrir e rodar o projeto

Após clonar o projeto, você pode abri-lo no Visual Studio Code. Para isso, clique em:

- **File - Open Folder**;
- Procure o local onde o projeto está e o selecione;
- Por fim clique em **Selecionar pasta**.
